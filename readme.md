ComfyUITools

This is a comfyUI tools that allows one to deal with batches of prompt with different patameters and save he result at different dir if one want to. It suppose to read the api version of workflows and read certain format of prompts, which will be patched into a task and automatically be executed through every prompt. If configed, customized save policy will be executed for furthur review.

There also will be a graph UI to manage all the input and maybe become a restful API or FastAPI for products level usage.
